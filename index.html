Features & Capabilities

✈️ Flight Control

  • Takeoff, land, and hover commands
  • Movement in all 6 directions (forward, backward, left, right, up, down)
  • Turning and rotation with absolute heading control
  • Emergency stop procedures
  • Automatic flight sequences

📊 Sensor Integration

  • Battery level monitoring
  • Range sensors (front, bottom) for obstacle detection
  • Barometric pressure sensor for altitude
  • IMU (accelerometer, gyroscope) for motion tracking
  • Temperature sensor with calibration options
  • Optical flow sensor

🎨 Display & Feedback

  • Drone LED control (RGB)
  • Controller LED control
  • Buzzer sequences and tones
  • Canvas drawing API
  • 0x88 batch image protocol (100× faster rendering)

🎮 User Input

  • Controller button detection
  • Joystick input reading
  • Real-time input processing

Quick Start

Installation

  1. Install Java Development Kit (JDK) 11 or newer
  2. Download CoDrone EDU Java library from GitHub Releases
  3. Set up your IDE (VS Code, IntelliJ IDEA, or BlueJ recommended)
  4. Add the JAR file to your project dependencies

Your First Program

import com.otabi.jcodroneedu.Drone;

public class FirstFlight {
    public static void main(String[] args) {
        Drone drone = new Drone();
        
        drone.pair();              // Connect to drone
        drone.takeoff();           // Start flying
        drone.hover(5);            // Stay in place for 5 seconds
        drone.land();              // Come back down
        drone.close();             // Disconnect
    }
}
