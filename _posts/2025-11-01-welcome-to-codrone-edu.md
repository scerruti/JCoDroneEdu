Welcome to the new CoDrone EDU Java documentation site! This comprehensive resource brings together everything you need to teach and learn programming with drones.

## What's New

We've just launched our complete Jekyll-based documentation portal featuring:

- **Student Guides**: 9 comprehensive tutorials from getting started to advanced projects
- **Teacher Resources**: 11 guides covering curriculum, standards alignment, and classroom management
- **Architecture Documentation**: Deep dives into design decisions, protocols, and implementation details
- **Complete Javadoc**: Full API reference for all 208 educational methods

## Key Features

### For Students
- Step-by-step flight tutorials
- Sensor integration guides
- Real-world project examples
- Debugging tips and tricks

### For Teachers
- Complete 14-week curriculum
- Standards alignment (AP CSA, CSTA, NGSS)
- Classroom safety procedures
- Lesson plans and assessment strategies

### For Developers
- API design patterns and principles
- 0x88 display protocol deep dive
- Contribution guidelines
- Technical architecture evolution

## Getting Started

1. **Students** - Head to the [Student Guide](/JCoDroneEdu/guides/student/) to begin your journey
