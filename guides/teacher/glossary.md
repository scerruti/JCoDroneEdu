## Key Terminology

### Programming Concepts

**Algorithm**
A step-by-step procedure for solving a problem or accomplishing a task. Example: Steps to fly a square pattern.

**Class**
A blueprint for creating objects in object-oriented programming. In JCoDroneEdu, `Drone` is a class.

**Compilation**
The process of converting source code into machine-readable bytecode (in Java).

**Constructor**
A special method that creates a new instance of a class. Example: `new Drone(true)`.

**Data Type**
A category specifying what kind of data a variable can hold. Examples: `int`, `double`, `boolean`, `String`.

**Exception**
An error that occurs during program execution. Handled using try-catch blocks.

**Function** (Method)
A reusable block of code that performs a specific task. Can take parameters and return values.

**Loop**
A control structure that repeats a block of code. Types: for loop, while loop.

**Object**
An instance of a class. Example: A specific drone object created from the Drone class.

**Parameter**
A variable passed to a function. Example: `moveForward(0.5)` has parameter 0.5.

**Scope**
The context in which a variable exists and is accessible. Example: Variables declared in a function are local to that function.

**Statement**
A single line of code that performs an action. Example: `drone.takeoff();`

**Variable**
A named container for storing data. Example: `int battery = 95;`

---

### Drone Concepts

**Altitude**
The height above sea level (calculated from barometric pressure).

**Attitude**
The orientation of the drone (pitch, roll, yaw) in 3D space.

**Barometer**
A sensor that measures air pressure to estimate altitude.

**Battery**
The power source for the drone. Typical flight time: 15-30 minutes per charge.

**Calibration**
The process of zeroing sensors or aligning systems. Example: Compass calibration for accurate heading.

**Drone** (Unmanned Aerial Vehicle, UAV)
A remotely controlled or autonomous aircraft.

**Elevation**
The height above ground level (calculated from barometer minus calibration offset).

**Flight Controller**
The onboard computer that stabilizes the drone and executes commands.

**Gimbal**
A mechanical mount that stabilizes a camera or sensor.

**Hover**
To maintain stable flight at a fixed position.

**IMU** (Inertial Measurement Unit)
A sensor that measures acceleration and rotation. Contains accelerometer and gyroscope.

**LED**
Light-emitting diode. Used for status indicators or user feedback.

**Propeller**
Spinning blade that generates thrust to fly the drone.

**Range Sensor**
An ultrasonic or infrared sensor that measures distance to obstacles.

**Thrust**
The upward force generated by propellers.

**Waypoint**
A GPS coordinate or position that the drone navigates to.

**Yaw**
Rotation around the vertical axis (turning left/right).

**Pitch**
Rotation around the horizontal axis (tilting forward/backward).

**Roll**
Rotation around the forward axis (tilting left/right).

---

### Hardware Terms

**Accelerometer**
A sensor component of IMU that measures acceleration (change in velocity).

**Brushless Motor**
An efficient motor type commonly used in drones. No brushes = longer lifespan.

**Compass** (Magnetometer)
A sensor that detects Earth's magnetic field for heading orientation.

**Gyroscope**
A sensor component of IMU that measures rotation speed.

**Motor**
The device that spins propellers to create thrust.

**ESC** (Electronic Speed Controller)
Controls the speed of drone motors based on commands.

**Transmitter**
The remote control device that sends commands to the drone.

**Receiver**
The onboard component that receives transmitter signals.

**USBC** (Communication Standard)
A standardized connection protocol for data transfer.

---

### Software Terms

**API** (Application Programming Interface)
The set of methods available for controlling the drone. JCoDroneEdu provides an API with methods like `takeoff()`, `moveForward()`, etc.

**Bytecode**
Compiled Java code that runs on the Java Virtual Machine (JVM).

**Compiler**
A program that converts source code to bytecode.

**IDE** (Integrated Development Environment)
A software tool for writing, compiling, and debugging code. Example: IntelliJ IDEA.

**JDK** (Java Development Kit)
Tools needed to write and compile Java programs.

**JVM** (Java Virtual Machine)
The runtime that executes Java bytecode on any computer.

**Library**
A collection of pre-written code (classes and methods) that programmers can use. JCoDroneEdu is a library.

**Package**
A folder/namespace for organizing classes. Example: `com.otabi.jcodroneedu.*`

**Protocol**
A set of rules for communication. Example: USB protocol for communicating with drone.

**Repository** (Repo)
A central location where code is stored and version-controlled (using Git/GitHub).

---

### Classroom Terms

**Breakpoint**
A point in code where a debugger pauses execution for inspection.

**Bug**
An error in code causing incorrect behavior.

**Debug**
The process of finding and fixing bugs in code.

**Pair Programming**
Two programmers working together on the same code—one typing, one reviewing.

**Pseudocode**
Human-readable description of algorithm, not actual code.

**Refactoring**
Restructuring code without changing its behavior, usually to improve clarity.

**Rubric**
A grading guide specifying criteria and how points are awarded.

**Test Case**
A specific scenario used to verify that code works correctly.

**Unit Test**
A small test verifying that one function works correctly in isolation.

**Version Control** (Git)
A system for tracking code changes over time.

---

### Physical Quantities

**Acceleration**
Rate of change of velocity. Measured in meters/second².

**Frequency**
Number of oscillations per second. Measured in Hertz (Hz). Used in sound commands.

**Gravity**
Earth's pull, approximately 9.8 m/s² downward.

**Height** (AGL)
Above Ground Level - distance to ground directly below.

**Magnitude**
The strength or size of a quantity.

**Pitch**
Tilting forward/backward. Also called "angle of attack."

**Roll**
Tilting left/right.

**Temperature**
Measure of thermal energy. Drones operate typically 32-104°F.

**Thrust**
Upward force. Must exceed weight to fly.

**Velocity**
Rate and direction of movement.

**Yaw**
Spinning left/right (heading change).

---

### Safety Terms

**Prop Guard**
Protective ring around propellers to reduce injury risk.

**Dead Zone**
Area around drone where no students are allowed during flight.

**Safe Mode**
Throttle limiting or other safety features to prevent uncontrolled flight.

**Failsafe**
Automatic action when control is lost. Example: Auto-land.

**IEEE**
Institute of Electrical and Electronics Engineers - technical standards body.

**ROS**

## Quick Reference Tables

### Loop Structures

| Structure | When to Use | Example |
|-----------|-----------|---------|
| `for` | Fixed number of iterations | `for (int i = 0; i < 4; i++)` |
| `while` | Condition-based, unknown count | `while (battery > 30)` |
| `for-each` | Iterate through array | `for (int value : array)` |

### Primitive Data Types

| Type | Range | Example |
|------|-------|---------|
| `int` | -2B to +2B | `int battery = 95;` |
| `double` | ±1.8E308 | `double altitude = 1.5;` |
| `boolean` | true/false | `boolean flying = true;` |
| `char` | Single character | `char key = 'A';` |

### Comparison Operators

| Operator | Meaning | Example |
|----------|---------|---------|
| `==` | Equals | `battery == 50` |
| `!=` | Not equals | `battery != 0` |
| `<` | Less than | `height < 100` |
| `>` | Greater than | `battery > 25` |
| `<=` | Less than or equal | `battery <= 80` |
| `>=` | Greater than or equal | `battery >= 50` |

### Logical Operators

| Operator | Meaning | Example |
|----------|---------|---------|
| `&&` | AND (both true) | `battery > 50 && height < 100` |
| `\|\|` | OR (one true) | `battery < 20 \|\| motor_error` |
| `!` | NOT (reverse) | `!isFlying` |
