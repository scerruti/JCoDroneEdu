## Why Drone Programming?

**Engagement:** Drones are cool. Students code something, and they watch it fly.

**Tangibility:** Unlike console output, drone behavior is immediate and visible.

**Complexity Management:** Start simple (takeoff/land), build to advanced (autonomous navigation).

**Real Skills:** Teaches core CS concepts through practical application:
- Variables and data types (battery level, position)
- Control flow (loops, conditionals)
- Functions and decomposition
- Debugging and testing
- Systems thinking

## Course Integration Options

### Option 1: Introductory CS (14 weeks)
Focus on core programming concepts with drones as vehicle

**Weeks 1-3:** Basic Java and drone API
**Weeks 4-6:** Control structures with flight patterns
**Weeks 7-9:** Functions and sensor integration
**Weeks 10-14:** Autonomous systems and projects

### Option 2: Robotics/Embedded Systems (Semester)
Deep dive into autonomous systems, sensors, and multi-robot coordination

### Option 3: Capstone Project (8 weeks)
Student-designed drone applications with creative extension
